# ASE 230 Support Ticket Assignment — Starter Scaffold

This starter project gives you the application structure and basic interface.
It is intentionally incomplete.

## Before You Start

1. Place the project in your local web-server document root.
2. Make sure PHP can read and write `data/tickets.json`.
3. Make sure PHP can write to the `uploads/` directory.
4. Open `index.php` through your local web server, not by double-clicking the file.

## Your Work

Search the project for `TODO`.

The TODO sections correspond to major assignment requirements, including:

- saving JSON data
- generating ticket IDs
- GET-based searching/filtering
- server-side validation
- secure file-upload processing
- creating new tickets
- POST-based status updates

You may add helper functions and reorganize the starter code if your final solution remains clear and functional.

## Important

Do not remove server-side validation simply because the HTML form contains browser-side validation attributes.

Do not hard-code a solution that works only for the three sample tickets.

Your application should continue to work after additional tickets are created.
